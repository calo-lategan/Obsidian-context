### Recommended Approach for Agent Sprites
Since you want **pre-made sprite sheets** in Octopath style:
1. Download OT:CotC sprites from Spriters Resource as **visual reference** (not for production use — they're copyrighted)
2. Use **Pixeline NPC Base** or **Memao Creator** to generate base characters
3. Customize colors/accessories per agent in an image editor (Aseprite, Piskel, or LibreSprite)
4. Each sprite sheet should be: **16x24px base, 4 directions × 4 frames walk + 2 idle + 3 work + 2 sleep = ~44 frames**

### What You Need for HD-2D Effects
- **Dust motes**: Small 4x4 or 8x8 soft glow circles (white/gold) — use OpenGameArt Particle Pack
- **Fireflies**: 2-frame 4x4 yellow/green glow — easily made in Aseprite or Pixel FX Designer
- **Light rays**: Triangular gradient sprites (can be generated in PixiJS with Graphics)
- **Smoke**: 8-frame smoke dissipation animation — Weenter Dust Clouds or Pixel FX Designer
- **Bloom glow**: Not a sprite — handled by PixiJS AdvancedBloomFilter on emissive layer
