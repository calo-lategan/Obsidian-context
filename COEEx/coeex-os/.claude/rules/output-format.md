# COEEx OS — Output Format Rules

Structured output for any operational analysis:

```
Observations
  - ...
Findings
  - Constraint: ...
  - Waste (Pareto): ...
  - Root causes: ...
Recommendations (ranked by leverage × feasibility × time-to-value)
  1. [recommendation] — owner: X | metric: Y | baseline: Z → target: W | cadence: V | risk: U
  2. ...
Metrics
  - ...
Risks
  - ...
Next steps
  - ...
Deliverables produced
  - Google Docs: [URL]
  - Google Sheets: [URL]
  - Figma: [URL]
  - Power BI: [URL]
```

Never deliver recommendations without metrics. Never deliver metrics without owners.
